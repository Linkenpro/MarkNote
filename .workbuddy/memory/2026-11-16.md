## MarkNote 仓库初始化（D:\VPS\MarkNote）

- 远端：`git@github.com:Linkenpro/MarkNote.git`（SSH），仓库public可读，默认分支 `main`。
- 首次拉取：工作区原本只有空的 `.git` + origin，无提交。用
  `git -c http.proxy=http://127.0.0.1:10808 fetch https://github.com/Linkenpro/MarkNote.git main`
  成功后 `git checkout -B main FETCH_HEAD`，204 个文件全部检出，HEAD=`ceb4c4c`。
- 本机代理：**10808 是混合端口（HTTP+SOCKS 兼容）**，`http://127.0.0.1:10808` 可用；2802(Privoxy)/10809/7890 均关闭。
- 关键坑：ssh 在中文用户名下**自己找不到 `~/.ssh`**（报 `Could not create directory '/c/Users/\324\264\272\343/.ssh'`），
  表现为 `Permission denied (publickey)`，看起来像密钥没配。实测密钥有效（`Hi Linkenpro!`）。
  修法：仓库级 `core.sshCommand` 用**绝对路径**指定密钥与 known_hosts：
  ```
  ssh -i "C:/Users/源恒/.ssh/id_rsa" -o IdentitiesOnly=yes \
      -o UserKnownHostsFile="C:/Users/源恒/.ssh/known_hosts" -o StrictHostKeyChecking=accept-new
  ```
  加完之后 `git fetch origin` 直接走 SSH 成功，`main` 已 track `origin/main`。
- 仓库级配置：`http.proxy` / `https.proxy` = `http://127.0.0.1:10808`，`core.quotepath false`（中文文件名正常显示）。
- 注意：本机没装 `gh`，没有 PAT；push 走 SSH 密钥可用，HTTPS push 无凭据。
